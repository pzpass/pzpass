# AGENTS.md

PzPass: zero-dependency Zig password generator + encrypted vault. Library `src/pzpass.zig`,
thin binary `cli/main.zig` → `pzp`. Zig 0.17+ (CI pins 0.17.0); targets Linux x86_64/arm64,
macOS arm64.

## Commands

```bash
zig build                                              # debug build; always reruns the gen step
zig build run -- pass 24                               # note the `--` (passthru args)
zig build test                                         # ~80s, 23 tests (Argon2id dominates)
zig test src/vault.zig --test-filter 'wrong password'  # focused run; `zig build test` takes no filter
zig build gen                                          # regenerate src/dicelist.zig
zig build clean                                        # deletes zig-out/, tmp/, .pzpass/ (not .zig-cache/)
zig build --release=small                              # what release CI ships
```

This is Zig 0.17: `std.process.Init`, `std.Io.Reader`/`Writer` over caller-supplied buffers,
`std.testing.io`/`environ`. Do not introduce pre-0.15 idioms (`std.io.getStdOut`,
`file.writer()` without `io`, etc.).

## Generated code

- `src/dicelist.zig` is generated by `tools/dicelist_generator.zig` from `dict/words.txt`
  and is rewritten by every `zig build`. Never hand-edit it; change the dict and run `zig build gen`.
- `dict/words.txt` has 10,399 words (README's "7776-word list" is stale).
- If the dict is missing, the generator's fallback "download" uses a GitHub blob URL
  (HTML, not raw) — treat that fallback as broken.

## Vault format is fragile

- `src/format.zig` serializes `Vault.Header`/`Vault.Entry` field by field; order and widths
  must mirror the structs. For v2 the header is AEAD associated data (`headerAuthData`), so
  reordering/retyping fields silently makes existing vaults undecryptable.
- Bump `Config.VERSION` on layout changes and keep the v1 path working
  (`version == 1` → empty AAD). The duplicated entry count is an integrity check, not redundancy.
- Per-entry cap is 16 MiB in `format.zig`; interactive input is capped at `Config.ENTRY_LEN` (4096).

## Security invariants

- Keep it dependency-free: `std.crypto` only (ChaCha20-Poly1305, Argon2id); `build.zig.zon` has
  no deps and its `.fingerprint` must not change.
- Sensitive buffers: aligned alloc (`std.heap.page_size_min`) → `mlockSlice` →
  `secureZero`/`zeroAndMunlock` → `allocator.rawFree(buf, alignment, page_size)`. Never use
  plain `free`/`deinit` on them.
- `mlock` is Linux-only (`src/crypto.zig`); on macOS it is a no-op, and on Linux failure returns
  `error.NotMlocked` (needs adequate `RLIMIT_MEMLOCK`).
- Vault writes: 0600 temp file → sync → existing file renamed `.bak` → rename temp (atomic; preserve).
- CI greps `src/` for `@ptrCast`, `@ptrFromInt`, `@intFromPtr`, `@alignCast`, `catch unreachable`,
  `orelse unreachable`, `@setRuntimeSafety(false)`, `@cImport`; avoid adding these.

## Testing

- Tests are inline `test "..."` blocks in each `src/*.zig`; there is no `tests/` directory.
  `zig build test` runs both the library module and the exe (dummy) tests.
- Tests use the real env/cwd and create `./.pzpass/` in the repo root (`*.vault.dat`, `.bak`,
  `mock.stored.file`). Gitignored; do not commit, and expect residue after a test run.
- `pzp dice` needs a TTY (calls `tcgetattr` on stdout → `NotATerminal` when piped);
  `pzp pass` pipes fine.

## CLI / docs drift

- Dispatch in `src/pzpass.zig` uses `std.mem.startsWith(u8, "<literal>", arg)`, i.e. the user's
  argument is a prefix of `"password"`/`"dicephrase"`: `pass`, `password`, `dice`, `dicephrase`
  all work; anything else prints usage. `-f` requires a filename argument.
- Default vault: `$HOME/.pzpass/$USER.vault.dat` (TUI only). README keybindings match
  `src/interactive.zig`; OVERVIEW.md's key list is stale.
- README install claim is stale: `--prefix "$HOME"` installs to `$HOME/bin/pzp`, not
  `~/.local/bin/pzp` (verified against Zig 0.17.1).

## CI

- PRs to `main` → `.github/workflows/checks.yaml`: `zig fmt --check src/ cli/ tools/`
  (continue-on-error), `zig build --summary all`, `zig build test --summary all`, Zig 0.17.0.
- Release workflows build `--release=small`. `security-audit.yaml` runs on pushes to non-main
  branches only (its call in `ci.yaml` is commented out).
